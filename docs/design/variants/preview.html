APW-115 · design review

Three dialects for one popup.

The same 336 × 206 instrument, the same four states of truth, three ways of being quiet. Written in the Apple idiom because the product is an Apple accessory — then held to Windows: an opaque-or-acrylic choice, a licence-safe typeface, and a system accent that is never assumed.

HTML approximation at 100 % scale, not a WPF render. Blur is CSS backdrop-filter standing in for DWM acrylic. Inter stands in for SF Pro; Cascadia Mono stands in for SF Mono. The blue is a stand-in for the Windows system accent, resolved at runtime.
01

Popover macOS material

A translucent system surface, full-bleed hairlines, monochrome numerals, and colour used only when a component needs attention. Of the three it is closest to how macOS presents an accessory, and the only one that depends on a Windows composition API to look right.

  • SurfaceVibrancy, not decoration. 72 % surface over a blur: the desktop shows through, the text never fights it.
  • Numbers26 px semibold, tabular. The per cent sign drops to 13 px and secondary grey, so the digits carry the eye.
  • ColourMonochrome numerals. Red only when a component is low, blue only for the charging bolt and a live connection.
02

Widget iOS battery widget

An opaque card with large numerals and capsule rails whose colour follows the level. It is the variant that reads as Apple in a screenshot, and the one that looks least like a Windows window. It needs no compositor support and no blur.

  • SurfaceSolid and edge-defined. 22 px continuous corners, no border, a shadow soft enough to imply elevation without a visible edge.
  • Numbers32 px, 640 weight, −3.5 % tracking. The value is the whole point of the cell; labels step back to 11 px secondary.
  • ColourThe rail carries level: green in normal range, red at 10 %. The number stays neutral so colour is never the only signal.
03

Studio Apple pro app

The instrument panel from Apple’s professional tools: near-black surface, hairline rules, monospaced figures, and ten discrete ticks instead of a continuous bar. Denser than the other two, and the easiest to justify inside a Windows tray.

  • SurfaceOpaque, 8 px corners, 1 px hairline border. Nothing floats; the panel is a tool, not a card.
  • Numbers21 px monospaced with tabular figures and a 11 px secondary per cent. Values line up as a column, which is what a pro app does.
  • ColourTen ticks per component, so the 10 % step is visible rather than smoothed. Accent is the charging bolt only.

Acrylic on Windows 11 is requested through DWMWA_SYSTEMBACKDROP_TYPE; on Windows 10 the same window needs an accent-policy fallback or an opaque fill. The choice changes the popup’s character, so it is a design decision, not a build detail.

My call: 01, with 03’s tick rail as the battery detail

Popover carries the Apple feeling without pretending to be macOS chrome: one material surface, full-bleed hairlines, numbers doing the talking. Its weakness is the acrylic dependency — if the WPF window cannot take a DWM backdrop, it degrades to a flat card and loses half its character. Studio is the safe build; Widget is the one that photographs best and belongs least on a Windows desktop.
